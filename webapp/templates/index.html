ℹ️ RESEARCH SYSTEM

About OM²AHL-BiG

Optimized Multi-level Mixed Attention enabled Hybrid Learning based Bidirectional Gradient model for intra-frame video forgery detection (Paper 2 · postdoc).

1 · Preprocessing

GetPreprocessing.py — adaptive key frames + Viola–Jones ROI (Haar cascade).

2 · Features

GetFeatures.py — GradCAM, ResNet-101 statistics, VGG-16+SIFT, shape-ResNet.

3 · Model

Model.py · BiLSTMGBM — BiLSTM + multilevel/mixed attention + incremental learning + GBM.

4 · Optimization

Optimization.py + vendored mealpy/Proposed.py (CoSH hybrid).

5 · Analysis

Analysis.py — TP 40–90% and K-fold 6–10 comparative / performance loops.

6 · GUI / Web

GUI.py desktop · webapp/app.py browser demo for Render.

Executable entry points

Main.py — full train or plot-only · GUI.py — interactive stages · driver.py — check / plots / gui / evaluate · webapp/app.py — this site · gunicorn app:app — production (Render).
